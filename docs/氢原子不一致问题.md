## 一、问题本质

原流程的"侧链质心"定义为：

```python
backbone = {'N', 'CA', 'C', 'O', 'OXT'}
atoms = [a for a in residue.get_atoms() if a.get_name() not in backbone]
centroid = mean([a.get_coord() for a in atoms])
```

**只按原子名排除主链，没有排除氢原子。**

而实验测定的 WT 结构与 FoldX 生成的 MT 结构在氢原子上根本不同：

| 结构类型 | 原子总数 | 氢原子数 |
|---|---|---|
| WT（实验结构） | 1119 | **582** |
| MT（FoldX BuildModel） | 543 | **0** |

于是：
- **WT 质心 = 侧链重原子 + 氢的质心**（被氢拉偏）
- **MT 质心 = 侧链重原子的质心**

两者**不是同一个量**，直接相减会产生大量**伪"断边"**。

### 7.3 🔴 重大反转：断裂接触其实是**局部**的

| 指标 | 数值 | 95% CI |
|---|---|---|
| 断裂接触 → 突变位点距离 | **4.01 Å** | [3.10, 5.37] |
| 保持接触 → 突变位点距离 | **15.44 Å** | [13.72, 17.97] |
| 断裂接触中位距离 | 2.68 Å | — |
| 断裂接触 < 5 Å 的比例 | 66.2% | — |

**论文 §3.3 原文**："across 446 mutations, broken and kept contacts have similar distances to the mutation site, differing by < 1 Å"

**这是错误的**——该结论被氢原子假象制造的大量"远端伪断边"稀释所致。
真实情况：**断裂接触高度局部化**（4.0 Å vs 15.4 Å，相差 11.4 Å）。

### 7.4 机制分析（修正后）

| 特征 | Pearson | 95% CI | Spearman | 偏相关（控制理化） |
|---|---|---|---|---|
| n_broken | 0.061 | [−0.027, 0.179] | 0.088 | 0.083 |
| n_formed | 0.083 | [−0.046, 0.209] | 0.055 | 0.071 |
| n_edit | 0.081 | [−0.020, 0.214] | 0.094 | 0.091 |

**VIF**：n_broken 1.32、n_formed 1.42（全部 < 2.4）→ **不存在共线性**。
**冗余性**：与理化特征最大 |r| = 0.18 / 0.24 / 0.12 → **不是高度冗余**。
**分层**：小 −0.015、中 0.084、大 0.101 → 扰动越大**并非**信号越强。
**距离依赖**：平均断边距离 vs ΔΔG：r = **0.005** → 与距离无关。

## 八、教训

这是继"抽样偏差"之后**第二个"看起来合理但实际错误"的结果**。
两个错误的共同点：**都是实现细节导致的人为假象**（一个是抽样不随机，一个是原子集不一致），都不是建模思想的问题。
**只有逐层核查原子级数据才能发现。**

更值得记录的是：氢原子假象**同时污染了三个结论**——
① 断边数量被放大 2.2 倍；② "断裂接触不局部"的错误结论；③ 案例（1BFM M35W）的选择。
一处实现细节错误，会沿着分析链条传播成多个独立"结论"。
