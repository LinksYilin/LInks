## 一、最严重问题：论文方法与实际代码不一致（确认属实）

### 事实核查

| 论文声称 | 实际代码 | 判定 |
|---|---|---|
| 可微 Graph Edit Distance | `gedmut_train.py` 是普通 2 层 GCNConv | ❌ 不实 |
| Sinkhorn 软匹配 | 无 PyTorch Sinkhorn；`ged_module.py` 是 NumPy 参考实现，不在 autograd | ❌ 不实 |
| 可学习节点/边编辑代价 | 只用固定 BLOSUM 标量 + flag，无可训练参数 | ❌ 不实 |
| 真实边编辑进训练 | `add_edit_features` 只加 BLOSUM 标量，无 WT/MT 边差分 | ❌ 不实 |
| GED_soft 参与训练 | 无 `ged_module.compute_edit_attribution` 调用 | ❌ 不实 |
| Hungarian 匹配 | 是逐行贪心（`ged_module.py` L41-60），非真 Hungarian | ❌ 名不副实 |
| GNN 用 edge_attr | `GCNConv` 不用 edge_attr | ❌ 不实 |

### 结论

论文的"可微 GED"叙事与实际代码（普通 GCN + 固定 BLOSUM）严重脱节。**必须走路线 B**：把论文收窄为"侧链质心接触图审计 + FoldX 接触重排描述 + 结构编辑特征有限增量研究"。
