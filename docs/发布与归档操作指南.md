## 第二步：在 Zenodo 生成 DOI

1. 用 GitHub 账号登录 <https://zenodo.org>
2. 进入 **Settings → GitHub**，找到 `contact-graph-ddg-benchmark`，把开关打开
3. 回到 GitHub，创建一个 **Release**（例如 tag `v1.0.0`，标题 `Initial release`）
4. Zenodo 会自动归档并生成 DOI（形如 `10.5281/zenodo.XXXXXXX`）
5. 记下两个值：
   - **概念 DOI**（Concept DOI）：始终指向最新版本，用于论文
   - **版本 DOI**（Version DOI）：指向 v1.0.0

> 若不想用 Zenodo 的 GitHub 集成，也可在 Zenodo 页面选择 **New upload** 手动上传
> `release/` 的 zip 包，同样会生成 DOI。
