## 关于摘要结构

BMC Bioinformatics 的摘要为**结构化摘要**，通常包含：
- Background
- Results
- Conclusions

当前稿件摘要使用 **Motivation / Results / Conclusion / Availability** 四段结构。
**建议**将 "Motivation" 改为 "Background"，并核对 "Availability" 是否应移入正文
（BMC 通常要求数据可得性写在 Declarations 中，而非摘要内）。
