## 三、关键结论（诚实）

1. **mutation-level 上，linear 最强（0.415）**，GNN local 次之（0.36-0.38），GNN global 最差（0.13-0.22）。
2. **固定 BLOSUM 特征无增量**：local_blosum（0.36）≈ local（0.36-0.38），甚至略低。
3. **protein-level 反常**：GNN global 的 protein-level Pearson（0.37-0.44）反而最高，与 mutation-level（0.13-0.22）矛盾。原因是 protein-level 只用 19 个蛋白（min_mut=5），且 Fisher-z 汇总的是"蛋白内排序相关性"，与 mutation-level 的"跨蛋白绝对预测"度量不同。**这提示 protein-level 结论对 min_mut 阈值和蛋白子集敏感，需谨慎解读，不能据此宣称 global 更好。**

## 四、与之前数字的差异

- 之前论文写 linear=0.383（543 条），现在共同交集 501 条上 = 0.415。
- 之前 GNN local=0.374（3 seed 均值），现在 0.355-0.380（3 seed 独立值）。
- 差异来源：样本数（543→501）+ bootstrap 修正（重复抽样）+ 训练随机性。
