## 一、重新定位论文叙事（最高优先级，0.5 天）

**动作**：标题、摘要、引言从"我们的方法没成功"改为"系统性基准评估"。

**核心问题句**：*Why does a mutation-sensitive graph representation fail to improve ΔΔG prediction?*

**叙事骨架**：
1. 现状：接触图是结构法标配，但"用哪种原子定义"从未被系统评估。
2. 我们做了一次**受控的表示层评估**：4 种图定义 × 固定训练/评估协议 × 防泄漏。
3. 发现：表示层对"结构描述"高度敏感（Cβ 完全不变 vs 侧链质心 94.3% 有变化），但对"预测性能"几乎无影响。
4. 机制：编辑特征与理化特征高度冗余；断裂接触的预测价值随距突变位点距离衰减。
5. 价值：给领域一个明确结论——**换接触图定义不能突破 ΔΔG 预测瓶颈**，瓶颈在别处（序列进化信息/训练数据多样性）。

**预期结果**：论文从"试错报告"升级为"有明确结论的评估研究"。

## 二、补充系统比较实验（核心补强，2–3 天）

| 子项 | 内容 | 可行性 |
|---|---|---|
| 2.1 | 4 种图定义：Cα、Cβ、侧链质心、全原子最小距离 | ✅ 需新建 2 套图 |
| 2.2 | 每种表示下"FoldX 建模前后边编辑数"分布（小提琴图） | ✅ |
| 2.3 | 边编辑数与实验 ΔΔG 的 Pearson/Spearman（含 95% CI） | ✅ |
| 2.4 | 按突变类型分层：体积增大/减小、极性变化、体积变化幅度 | ✅ |
| 2.5 | 所有统计：蛋白簇 bootstrap（B=1000），报告效应量 | ✅ |

**关键代码框架**：扩展 `build_contact_graph.py` 支持 `--atom-def {ca,cb,centroid,allatom}`。

**常见坑**：
- 全原子最小距离图计算量大 → 用 KD-tree（`scipy.spatial.cKDTree`）。
- 阈值不能只固定 8 Å → 需做 6/7/8/9/10 Å 敏感性。
- Cα 图与 Cβ 图高度相关 → 需报告两者边集 Jaccard 相似度（说明不是独立对照）。

## 四、机制分析：解释"结构敏感但不提升预测"（1–2 天，**论文最大增值点**）

| 子项 | 内容 | 可行性 |
|---|---|---|
| 4.1 | 编辑特征与 5 个理化特征的偏相关（控制理化的偏相关） | ✅ |
| 4.2 | 断裂接触"距突变位点距离"分箱 vs 预测价值（衰减曲线） | ✅ 需 3D 坐标 |
| 4.3 | 按体积变化幅度分层：小/中/大组的编辑特征相关性 | ✅ |
| 4.4 | 冗余度量化：方差膨胀因子 VIF / 主成分分析 | ✅ |

**至少完成 4.1 + 4.2 + 4.3**（用户要求至少两项，建议全做）。

**预期机制解释**：
- ΔΔG 的主导方差来自"突变残基自身理化性质"（单点局部效应）；
- 接触编辑是**该局部效应的下游结果**，携带信息被理化特征"前置包含"；
- 因此编辑特征在控制理化后条件独立于 ΔΔG → 增量近零。

**这是论文的核心科学论点**，比单纯报"r 没提升"有价值得多。
