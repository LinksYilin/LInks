### 清理过程

### 豁免规则及理由（均写入 ruff.toml）

| 规则 | 理由 |
|---|---|
| `RUF059`（解包未使用变量） | 科学代码中 `residues, seq = extract_residues(...)` 的对称解包比 `residues, _ = ...` 更可读；右侧两个返回值都是有意义中间量。13 处均属此类 |
| `BLE001` / `S110`（宽泛异常捕获） | **诊断脚本**需逐个尝试解析任意第三方 PDB，单条失败不应中断整体诊断；**门禁脚本**需容错并继续；**seed_utils** 为兼容不同 torch 版本。均按文件逐项豁免 |
| `SIM115`（未用上下文管理器） | 长流程中跨语句持有文件句柄（中途 return 会提前关闭） |
| `RUF015`（单元素切片） | 换取可读性，且不涉及性能瓶颈 |

> 豁免是**按文件、按规则**逐条声明并附理由，不是整体关闭规则集。

### 清理过程中发现并修复的自身引入问题（诚实记录）

自动修复脚本本身引入了 3 类破坏，均已发现并修复：
