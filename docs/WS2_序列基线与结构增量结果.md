# WS2 结果：序列基线与结构增量

> 本轮用 ESM-2 653M 建立了现代序列基线，并完成"结构在序列之上是否有增量"的关键检验。
> **所有数字来自实测**（训练/测试严格分离，见下方方法说明）。

---

## 一、ESM-2 三层基线

| 模型 | S669 | ssym |
|---|---|---|
| **ESM-2 zero-shot**（掩码边缘打分） | **0.317** [0.183, 0.446] | **0.266** [−0.008, 0.403] |
| **ESM-2 有监督**（冻结嵌入 + MLP 头） | **0.368** | **0.474** |
| **ESM-2 有监督**（全 2560 维嵌入 + 宽头，融合实验中的 ESM 分支） | **0.392** | **0.516** |

- zero-shot 无需训练，作为无监督参照点
- 有监督在同训练集（MegaScale + ThermoMutDB，7905 例）上训练，测试严格分离
- Spearman（zero-shot, S669）= +0.346

## 二、★ 核心实验：结构在序列之上是否有增量（WS2c）

### 设计

三个模型在同一划分、同一协议下训练与评估：

| 模型 | 输入 |
|---|---|
| **ESM-only** | 冻结的 ESM-2 嵌入（2560 维 = 全局均值 + 突变位点上下文） |
| **Graph-only** | 接触图 DeepGINE（6 层 GINE + 边特征 + 注意力池化 + 局部读出） |
| **ESM+Graph** | 双分支拼接 → MLP |

配对检验：**ESM+Graph 相对 ESM-only 的 Δr**，蛋白簇 bootstrap（B=2000），3 个种子。

### 结果

| 模型 | S669 (n=508) | ssym (n=342) |
|---|---|---|
| ESM-only | 0.392 | 0.516 |
| Graph-only | 0.368 | 0.460 |
| **ESM+Graph** | **0.379** | **0.540** |

### ★ 结构增量（配对检验）

| 基准 | Δr | 95% CI | p | 判定 |
|---|---|---|---|---|
| **S669** | **−0.013** | [−0.036, +0.010] | 0.274 | **无增量**（点估计略负） |
| **ssym** | **+0.025** | [−0.007, +0.070] | 0.138 | **无增量**（CI 含 0） |

**结论**：在两个基准上，**在强序列基线之上加入接触图表示，都得不到可靠增量**。
点估计量级仅 ±0.01–0.02，且置信区间均包含零。

## 三、为什么这个结果比原来的论文更有力

| 原论文 | 现在 |
|---|---|
| 只比较"换图定义" | 增加了"**结构 vs 序列**"的正面比较 |
| 无强序列基线 | ESM-2 653M zero-shot + 有监督 |
| 最强图编码器是 2 层 GCN | **6 层 GINE + 注意力池化**（460K 参数） |
| 可能被质疑"弱模型" | 图模型单独达 0.368/0.460，**接近 ESM 的 0.392/0.516** |
| 结论：本次设置内无差异 | 结论：**在强序列基线上，结构表示无可靠增量** |

**关键**：Graph-only 已经做到接近 ESM-only 的水平（差距 0.024/0.056），
说明图分支**不是欠拟合的弱模型**；即便如此，融合仍无增量。
这直接回应了"是你的模型太弱"的质疑。

## 四、诚实边界

| 边界 | 说明 |
|---|---|
| **ESM-2 预训练数据** | ESM-2 训练于 UniRef，S669/ssym 蛋白**可能已在其训练集中**。zero-shot 受影响较小（无 ΔΔG 监督），但**必须写进 Limitations** |
| **ssym 仅 15 蛋白** | CI 较宽；本站的 +0.025 增量 CI 为 [−0.007, +0.070] |
| **未做 MSA 模型** | 本地无 MSA 生成工具（HHblits/Jackhmmer），故未复现 MSA-Transformer，仅引用 |
| **S669 曾参与开发** | 其估计应视为探索性 |

## 五、方法学说明（可复现）

- **训练集**：MegaScale（train_s669 划分）+ ThermoMutDB，各自防泄漏过滤后 1:1 采样
- **测试集**：S669 共同交集 508（有 ESM 嵌入者）/ ssym 342
- **ESM-2**：`facebook/esm2_t33_650M_UR50D`，fp16，冻结权重
- **嵌入**：全序列平均 + 突变位点上下文，各 1280 维
- **图编码器**：`strong_backbones.DeepGINE`（6 层 GINEConv，hid=128，k-hop=2）
- **种子**：42 / 123 / 2024，预测取种子均值
- **统计**：蛋白簇 bootstrap（B=2000），重复簇保留
- **脚本**：`src/esm2_zeroshot.py`、`src/esm2_supervised.py`、`src/esm2_fusion_fast.py`
- **结果文件**：`data/esm2_zeroshot_*.csv`、`data/esm2_sup_*.csv`、`data/esm2_fusion_results.csv`
